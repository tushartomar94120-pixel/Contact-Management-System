# Contact-Management-System
The Contact Management System is a Python-based console application designed to efficiently manage personal or business contacts. It allows users to store, search, update, delete, and display contact information using Python dictionaries as the primary data structure. The project also includes data persistence through JSON files, ensuring that contact information is saved even after the program is closed. Additional features such as contact categories, CSV export, backup creation, and statistics make the application more practical and user-friendly.
